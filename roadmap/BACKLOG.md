1. **Manage menu sections (Admin > Menu > "Menu sections", open by default).** Becca can now **add** a section (emoji + name), **rename** it or change its emoji, **move it up / down**, **hide / show** it and **delete** it. Delete is only enabled for an empty section (so no item can be left without a section); a section that has items shows "Move or delete its items first". Hiding a section hides its items everywhere customers look (Menu page, Home, "Shop by treat", the header menu, and the cart: an item already in someone's cart from a hidden section is dropped as "no longer available"). The section's `id` never changes on rename, so `menu.html?c=...` links keep working; a link to a hidden or deleted section falls back to "All". The Menu page buttons, the header Menu dropdown and the Home "Shop by treat" tiles all read the same ordered list, so they follow the order and visibility automatically. In the Add / Edit item form, hidden sections are marked "(hidden)"; with no sections at all the form says to add one first. Data: `categories[]` in `products.json` gains an optional `hidden: true`; `store.js` `SB.load()` now also returns `shownCategories` and `shownProducts` (what customers get), while the admin keeps using `categories` / `products` (everything).
2. **"New" badge.** Items added in the last **14 days** (counted from the `added` date that every new item already gets) show a small outlined **NEW** badge next to the name on every product card; sold-out items show only the sold-out badge. Admin > Theme & layout > Home page has a **"New" badge stays for** dropdown (Off / 1 week / 2 weeks / 4 weeks; saved as `newDays` in `site-settings.json`, default 14). The Menu items list in admin shows a "new" tag on items that currently have the badge. The sample menu already has two recent items, so you will see it straight away.

Tests (headless browser, file://, 1100px and 360px): added "Cookies", renamed "Small Treats" to "Treats", moved Cookies above Bread, hid Bread: admin order, Menu page buttons, header dropdown and Home tiles all matched and Bread's items disappeared; `?c=bread` fell back to All; Delete is disabled on a section with items; a new item in the new section got the New badge and the admin "new" tag; setting the badge to Off removed every badge; the section manager has no sideways scroll at 360px; every link from `preview.html` loads with no script errors (the only console errors in the sandbox were Google Fonts being unreachable offline, as before).

Notes: like the rest of the admin, section changes are saved on this device until you **Publish** (replace `products.json` and `offline-data.js` together, and `site-settings.json` if you changed the badge length). The sample data files were not changed, so `offline-data.js` did not need regenerating. When the Supabase version (v10.16) arrives, sections move to the database with everything else.
